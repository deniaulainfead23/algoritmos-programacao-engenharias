# Fontes e referências didáticas

## Plano de Ensino
Plano de Ensino da unidade curricular Algoritmo e Programação - UNIG.

## Unidades de Aprendizagem usadas nesta organização
- UA1 - Os principais componentes de um computador
- UA2 - Entradas, Saída e Interrupções Programadas
- UA3 - Gerenciamento de entradas e saídas
- UA4 - Introdução a Algoritmos e Lógica de Programação
- UA5 - Desenvolvimento de algoritmos sequenciais através de fluxogramas
- UA6 - Representação de algoritmos em forma de pseudocódigo
- UA7 - Desenvolvimento de algoritmos sequenciais através de pseudocódigo (VisuAlg)
- UA8 - Comandos condicionais de múltipla escolha (pseudocódigo)
- UA9 - Comandos condicionais compostos (pseudocódigo)
- UA10 - Fluxo de Controle: Estruturas de Decisão
- UA11 - Estruturas de Repetição
- UA12 - Estruturas de Dados Homogêneas do Tipo Matriz
- UA13 - Introdução aos sistemas microprocessados e sistemas microcontrolados
