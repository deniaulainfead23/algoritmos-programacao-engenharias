# Algoritmos e Programação para Engenharias

Materiais didáticos da disciplina **Algoritmo e Programação** para os cursos de:

- Engenharia de Produção
- Engenharia Mecânica
- Engenharia Elétrica

## Objetivo

Desenvolver raciocínio lógico, abstração, modelagem de problemas e construção de algoritmos aplicados a situações de Engenharia.

## Organização didática

As aulas presenciais acontecem às **segundas-feiras, das 18h30 às 19h50**.

Cada encontro segue, preferencialmente, esta estrutura:

1. revisão lúdica de conhecimentos anteriores;
2. apresentação simples do novo conteúdo;
3. exemplo aplicado à Engenharia;
4. construção coletiva de algoritmo;
5. prática guiada;
6. exercício de revisão;
7. fechamento e ticket de saída.

## Regra das Unidades de Aprendizagem

Cada aula utiliza **no máximo duas UAs como base de conteúdo novo**.

A origem é sempre indicada no início do material de cada aula.

## Conteúdo até a Avaliação Integradora (AI)

O plano de ensino possui **13 Unidades de Aprendizagem (UA1 a UA13)**.  
Todo o conteúdo novo será concluído antes da AI, reservando as duas aulas imediatamente anteriores para revisão e consolidação.
