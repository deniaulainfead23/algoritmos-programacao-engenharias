# Aula 9 - Do algoritmo ao mundo físico

**Data:** 05/10  
**Conteúdo-base:** **UA13 - Introdução aos sistemas microprocessados e sistemas microcontrolados**

## Objetivos
- diferenciar, em nível introdutório, microprocessador e microcontrolador;
- compreender sistemas embarcados;
- relacionar entrada, processamento, decisão e saída ao hardware;
- integrar os conceitos estudados na disciplina.

## Revisão lúdica
Mostre a situação: “sensor detecta temperatura alta e liga ventilador”. Alunos identificam:
entrada -> processamento -> decisão -> saída.

## Sistema embarcado
Sistema computacional dedicado a uma função específica e integrado a um equipamento maior.

## Microprocessador x microcontrolador
Em abordagem introdutória:
- microprocessador: unidade de processamento que normalmente depende de outros componentes externos para formar o sistema;
- microcontrolador: integra CPU, memória e periféricos de entrada/saída em um único circuito destinado frequentemente a controle embarcado.

## Fluxo integrado
Sensor -> entrada -> algoritmo -> decisão -> atuador/saída.

## Aplicações
- Produção: controle de esteira.
- Mecânica: controle de temperatura ou rotação.
- Elétrica: monitoramento e proteção de circuitos.

## Atividade integradora
Projetar no papel o comportamento de um sistema automático:
1. definir sensor/entrada;
2. definir variável;
3. definir condição;
4. definir ação;
5. desenhar fluxograma;
6. escrever pseudocódigo.
