# Aula 3 - Variáveis, tipos de dados e operadores

## Essencial
- variáveis;
- inteiro, real, lógico e texto;
- operadores aritméticos, relacionais e lógicos;
- MOD e DIV;
- leitura, atribuição e escrita;
- tabela-verdade.

## Conexão com Engenharia
Representar quantidades de peças, temperaturas, correntes, tensões, estados de equipamentos e resultados de cálculos.
